# PASE Console - Predictive Analytics for Sustainable Energy

A professional industrial energy grid operations monitoring dashboard with real-time supply, demand, and battery management.

## Features

- **Real-time Monitoring**: Live tracking of energy supply and demand.
- **Predictive Analytics**: ML-driven forecasts for grid stability.
- **Battery Management**: Intelligent storage monitoring and control.
- **Fault Simulation**: Test grid resilience with customizable fault injections.
- **Professional Reports**: Export operational data to CSV and PDF.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Shadcn UI.
- **Backend**: FastAPI, Python, Scikit-learn (ML models).
- **Icons**: Lucide React.
- **Charts**: Recharts.

## Getting Started

### Prerequisites

- Node.js (v18+)
- Python (v3.9+)

### Installation

1. **Frontend**:
   ```bash
   cd frontend/gridsync-operations-main
   npm install
   npm run dev
   ```

2. **Backend**:
   ```bash
   cd backend
   pip install -r requirements.txt
   python main.py
   ```
